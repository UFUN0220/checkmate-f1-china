# 公开字段策略

> 状态：`superseded`。新版公开字段以 [`data/checkee-data-dictionary.md`](data/checkee-data-dictionary.md) 为准；旧版允许学校、精确面签日期、Case Update、备注和 `verified_for_publish` 的规则不再适用于 Checkee 公开数据。本文件保留阶段 1 历史证据。

## 适用范围

本策略适用于 Demo 的三级下钻。只有 `reviewStatus = verified_for_publish` 的记录可以进入公开统计和案例列表；内部原始字段、审核记录和源表行号永不公开。

## 字段决策

| 字段                  | Demo 是否允许 | 条件与处理                                                                                     |
| --------------------- | ------------- | ---------------------------------------------------------------------------------------------- |
| 申请地点              | 允许          | 仅限中国大陆地点规范值。                                                                       |
| 学位/宽泛专业         | 允许          | 使用规范化值；小样本必须显示样本量并避免过度结论。                                             |
| 学校                  | 允许          | 仅人工审核后公开；先清除联系方式、身份标识和自由文本中的敏感片段。                             |
| 精确面签日期          | 允许          | 当前 Demo 明确允许；必须经过日期和重识别风险审核，不得由日期推断结果。                         |
| Case Update           | 允许          | 只能发布清洗后的公开版本；移除联系方式、案件号、身份信息和未经审核的原文片段。                 |
| 备注                  | 允许          | 只能发布人工审核后的安全版本；移除联系方式、案件标识、学校邮箱和可识别细节。                   |
| 来源状态              | 允许          | 可展示 `Check`/`Approve` 等规范状态；`Approve` 不等于 `Issued`，`Refused` 不自动等于最终拒签。 |
| 匿名临时 ID           | 允许          | 只能使用构建期安全字段生成，不能来自邮箱、学校、备注、Case Number 或完整原始行普通哈希。       |
| 联系方式              | 禁止          | 邮箱、手机号、微信、QQ、社交账号及其提示词全部删除。                                           |
| 案件标识              | 禁止          | CEAC Case Number、护照号、SEVIS ID、DS-160 编号及相似标识全部删除。                            |
| 身份字段              | 禁止          | 姓名、学校邮箱、审核人员、提交者信息及可直接识别个人的组合全部删除。                           |
| 源表行号/原始文件路径 | 禁止          | 只保留私有审计链路，不出现在前端、公开 JSON、日志或 source map。                               |

## 质量门禁

公开生成前后都必须扫描邮箱、手机号、微信/QQ、案件标识、URL 查询参数和明显身份组合。命中即阻断公开构建。Case Update 与备注不得直接从原始自由文本复制到 `public/`；必须先产生清洗后的公开字段并记录审核结论。

公开展示始终标注：这是本站人工审核后的众包样本，不是官方数据、官方概率、个案预测或完全真实性认证。
