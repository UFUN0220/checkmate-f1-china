# CheckMate F1 China：产品动机与新版范围

状态：有效（阶段 3 新版需求迁移）

## 产品定位

CheckMate F1 China 是面向中国大陆 F-1 学生的 Checkee 公开数据垂直观察工具。Checkee 负责收集和公开用户自报案例；本项目负责聚焦 F-1、标准化来源字段、解释统计口径，并用适合移动端的界面组织信息。两者是数据来源与信息产品的上下游关系，不是镜像站，也不是 Checkee 的替代品。

## 为什么做

Checkee 覆盖多种签证类型和较长历史周期，适合查询单条记录，但 F-1 学生需要反复筛选才能理解当前公开样本的地点差异、Pending 等待年龄、Clear 完成时长和近期状态变化。本项目的价值不是重新建立案例投稿系统，而是把已经公开的数据组织成更容易阅读、比较和传播的 F-1 观察界面。

## 核心痛点

- 多种签证类型混在一起，F-1 用户筛选成本高。
- 长表格不利于快速理解地点分布、状态构成和时间趋势。
- Pending 等待年龄与 Clear 已完成时长容易被混为一谈。
- 数据范围、快照时间和样本限制不够突出时，容易被误读成官方结论。

## 唯一数据范围

- 来源：Checkee.info 公开页面。
- 起始日期：`checkDate >= 2026-01-01`。
- 签证类型：只保留经显式 alias 映射确认的 F-1 / F1。
- 地点：北京、上海、广州、沈阳、武汉及已确认的拼写变体；无法映射的地点排除并计入质量报告。
- 状态：保留来源语义，标准化为 `pending`、`clear`、`reject`、`unknown`。

旧 Excel、80 条旧案例、旧的人工审核/本地投稿路线、PIVIB、CEAC 和其他来源均不再属于产品数据范围。

## 30 秒回答目标

用户应能快速回答：

1. 2026 年以来 Checkee 收录了多少中国大陆 F-1 公开样本？
2. 当前 Pending、Clear、Reject 各有多少？
3. Pending 案例截至快照日已经等待多久？
4. 已 Clear 案例的实际完成时长如何分布？
5. 五个面签地点分别是什么情况？
6. 是否有地点、时间和专业分类相近的公开标准化案例？
7. 当前数据截至什么时候，是否可能已经过期？

所有回答都必须同时显示来源、统计范围、样本量、snapshotDate 和非官方限制。项目不计算普通申请者被 Check 的概率，不承诺个人出签时间，也不提供法律意见。
