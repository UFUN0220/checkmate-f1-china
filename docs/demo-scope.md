# Demo 范围

> 状态：`superseded`。本文件是阶段 1 的旧 Demo 范围，保留供历史追溯；新版范围以 [`product-rationale.md`](product-rationale.md) 为准，不再使用旧 Excel、人工审核或本地投稿路线。

## 目标

本阶段为 CheckMate F1 China 落盘一个可比较、可实现的 Demo 目标，不实现完整页面。Demo 只关注中国大陆申请地点的 F-1 Check 案例，使用当前 80 条样本作为结构基线。

## 三级下钻

### 一级：全国样本概览

- 产品名、非官方/众包说明、数据更新时间和方法入口。
- 当前样本总数与五个地点的“本站样本分布”。
- 主导航使用横向分段比例条和五个地点卡片；环形图不能作为唯一入口。
- 提供“提交/更新” CTA 占位，当前阶段不接收数据、不连接外部文档。

### 二级：地点指标

点击地点卡片后，显示该地点的：

- 样本数、Check 数和本站样本占比；
- pending age 的平均值、中位数、P75 和最长值，明确标注“当前等待年龄”；
- 面签日期范围、Approve 数、学位构成和宽泛专业构成；
- 方法说明、样本量和返回全国概览入口。

地点百分比只能称为“本站样本分布”，不能称为领馆 Check 率、官方比例或领馆处理速度。小地点的 n=3/7/13 必须显示样本量和小样本提示。

### 三级：人工审核案例记录

从地点指标点击“查看案例”或某个可下钻指标后，展示人工审核且允许公开的记录。默认只显示 `verified_for_publish`，公开字段遵循 [`public-field-policy.md`](public-field-policy.md)。

案例列表支持返回地点指标和全国概览；不要求登录，不收集护照号、DS-160、SEVIS ID、CEAC Case Number、姓名、邮箱、微信或 QQ。

## 不在本阶段实现

- 完整生产页面、图表交互、相似案例算法和视觉方向选择。
- 数据库、登录、用户追踪、腾讯文档 API、网页抓取、Cookie 或浏览器登录态同步。
- AI 预测、个案通过率、倒计时、预计出签日期和“今年更严重”等同比结论。
